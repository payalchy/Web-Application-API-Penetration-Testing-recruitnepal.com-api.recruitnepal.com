# Web-Application-API-Penetration-Testing-recruitnepal.com-api.recruitnepal.com
Web Application &amp; API Penetration Testing for  recruitnepal.com &amp; api.recruitnepal.com
Tools: Burp Suite, Katana, GAU, SubJS, Wappalyzer, WAFW00F, Nmap, FFuF, Gobuster, Kali Linux
●	Ran a multi-phase engagement on a live production platform: reconnaissance, vulnerability assessment, and exploitation of SQL injection, stored/reflected XSS, and JWT-based role manipulation; uncovered exposed dev and mail admin panels.
●	Extended the assessment to CSRF/IDOR, clickjacking, file-upload risk, XXE/SSRF, and security header review across both the main domain and API subdomain.
●	Reviewed error handling for information disclosure, checked for exposed sensitive files (.git, .env), and fingerprinted framework versions against known CVEs.
●	Delivered a client-ready report with PoC evidence, severity ratings, and remediation guidance, and supported verification of deployed fixes.
